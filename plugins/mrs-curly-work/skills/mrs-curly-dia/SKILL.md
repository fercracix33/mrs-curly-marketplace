# Preparar el día

Aplica [el contrato común](references/operacion.md). Empieza por `polihair_morning_brief` con argumentos planos `{}`. Sus contadores representan el salón completo, aunque las listas estén paginadas.

Para «qué requiere mi atención», presenta prioridades concretas a partir del resumen. No llames a cada módulo ni abras cada conversación si ese resumen ya responde. Distingue citas de hoy, conversaciones sin responder, propuestas pendientes y alertas de stock.

Si se pide una lista completa de pendientes, recorre la paginación pertinente y consulta solo las fichas necesarias para identificar la acción. Si se pide otra fecha, usa las herramientas de agenda con la fecha local del salón; el resumen matinal no es un informe histórico.

Una consulta de prioridades no autoriza aprobar propuestas, enviar mensajes, ajustar stock ni cambiar citas.
